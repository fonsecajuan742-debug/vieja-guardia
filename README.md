# Vieja Guardia Urban

Tienda demo de streetwear urbano (Colombia).

## Incluye
- **36 productos** (12 tenis, 12 ropa, 12 gorras)
- Carrito funcional (localStorage)
- Checkout con **Nequi, PSE, tarjeta y contraentrega**
- Sección **Looks** (outfits completos de un clic)
- **FAQ** interactivo
- Newsletter, testimonios, filtros por marca/tipo
- Diseño responsive profesional

## Cómo verla
1. Descarga `index.html` del repositorio (o el archivo que te pasé en el chat)
2. Ábrelo en Chrome / Firefox
