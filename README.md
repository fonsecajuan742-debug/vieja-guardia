# Vieja Guardia Urban

Tienda demo de streetwear urbano (Colombia).

## Incluye
- Catálogo de tenis, ropa y gorras (12 productos por categoría)
- Carrito funcional (localStorage)
- Checkout con Nequi, PSE, tarjeta y contraentrega
- Looks completos, FAQ, newsletter
- Diseño responsive

## Cómo verla
Abre `index.html` en el navegador.

Repo: https://github.com/fonsecajuan742-debug/vieja-guardia
